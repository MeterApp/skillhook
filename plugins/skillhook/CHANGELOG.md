# Changelog

The plugin's version is the version of the `@meterapp/skillhook` npm package its MCP servers run, so
the plugin's changes are listed with the package's in
[CHANGELOG.md](https://github.com/MeterApp/skillhook/blob/main/CHANGELOG.md) on GitHub.

## 0.15.1

- The plugin now lives in its own folder (`plugins/skillhook/` in the repository) with its own README,
  which states what it runs and sends and how sign-in works. Install commands are unchanged.
